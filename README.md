# Formato de textos académicos con normas APA (7.ª edición) en Google Docs

Este Recurso te va a permitir aplicar las normas APA (7.ª edición) al formatear documentos académicos en Google Docs.

## ¿Qué incluye?

- **Sitio web interactivo** (`index.html`): : guía principal del taller, organizada como recurso web interactivo para aplicar el formato APA 7.ª edición en Google Docs. Incluye configuración inicial del documento, portada, estilos de títulos, revisión de citas, lista de referencias, herramientas de Google Docs, ejemplos de “antes/después” y una lista de control autoevaluable.
- **Guía Normas Apa** (`Guia-resumida-Apa-septima-edicion-2024.pdf`): documento de consulta sobre normas APA 7.ª edición. Se utiliza como apoyo para revisar criterios de formato, presentación del trabajo académico, citas, referencias, márgenes, interlineado, numeración, títulos y organización general del documento.
- **Acceso a sitio** (`https://normas-apa.org/`): sitio web de consulta complementaria sobre normas APA 7.ª edición. Permite ampliar información sobre formato, citas, referencias y ejemplos de aplicación en trabajos académicos.
- **Logo institucional** (`logo_IFD_Trinidad_2026.png`): imagen institucional que solicitan los docentes para su descarga.
